# 快手自动发布助手 · 使用说明

## 怎么启动（30 秒搞定）

1. 打开文件夹 **快手自动发布助手**；
2. 双击 **启动工具.exe**（推荐，不会出现命令提示符窗口）；
3. 等两三秒，出现「快手自动发布助手」窗口就成功了。

如果双击 exe 没有反应，可以改用 **启动工具（无窗口）.vbs**；需要看启动过程时再用 **启动工具-显示日志.bat**。

第一次打开会自动弹出「引导设置」，三步填完就能用；如果误关了，点右上角「引导设置」再开一次即可。

> 如果双击后一闪而过或提示找不到 Python，把弹出的提示内容截图发给助手。

## 一、它替你做什么

- **第一阶段（快手创作者服务平台）**：按账号一条一条上传视频 → 标题填成对应广告语 → 发布 → 确认发布成功 → **等 10 秒** → 下一条。
- **第二阶段（磁力金牛）**：用当天每条广告语在素材库里**搜索**，把搜到的那条素材的素材名改回**对应的视频文件名**（方便统计小组业绩）；如果搜索匹配不上，会自动改用"按上传时间倒序"的方式（金牛默认最新在最上面，所以列表第 1 条对应文件夹里最后一条视频）。
- 全程**一个账号跑完再跑下一个**，绝不并发；投放计划、选素材、出价仍然你手动做。

它不会做的事：新建投放计划、选素材投放、出价、删除作品、修改作品可见性。

## 二、账号和浏览器都不限定

- **账号数量随意**：主界面有「＋ 添加账号 / － 删除最后一个账号」，设置页也有「＋ 添加账号」。你有几个账号就加几行。
- **浏览器不限定**：每个账号可以单独选浏览器。工具会自动探测本机已安装的 Chromium 内核浏览器（Google Chrome、Microsoft Edge、Brave、360 极速、QQ 浏览器、搜狗、Vivaldi、Opera 等），选哪个都行。
- **登录方式两选一**：
  - `新建：首次扫码登录（推荐）`：不动你现在用的浏览器，新开一个干净的自动化窗口，第一次扫码登录一次，之后长期有效。**同事的浏览器如果没有多用户配置，选这个最省事。**
  - `复用：某个已有配置`：把已经登录好的浏览器配置复制一份出来用（你的 4 个 Chrome 用户配置就是这种方式，一个配置对应一个账号）。

## 三、界面长什么样

三个页签：

| 页签 | 干什么用的 |
| --- | --- |
| **今天要发的** | 每天主要就待在这一页：选文件夹、粘贴广告语、点「开始上传发布」 |
| **设置** | 第一次配好即可：账号增删、浏览器、平台网址、运行节奏、金牛改名方式 |
| **使用帮助** | 图文说明 + 常见问题，出问题时点「复制诊断信息」发给助手 |

「今天要发的」页每个账号一行，颜色一眼看懂：

- 灰色：未启用（今天不发这个账号）
- 橙色：还缺素材文件夹，或者还没粘广告语
- 红色：视频和广告语数量对不上
- 绿色：已配对，可以开跑

## 四、第一次使用（大约 5 分钟）

1. 双击 **启动工具.exe**，按引导设置走三步：
   - 第 1 步：加账号（有几个加几个），给每个账号选浏览器和登录方式（建议"新建：首次扫码登录"）；
   - 第 2 步：粘贴两个网址——创作者平台「发布作品」页、磁力金牛「视频库 / 素材库」页（在浏览器打开后复制地址栏）；
   - 第 3 步：给每个账号选当天放视频的文件夹。
2. 到「设置」页，选一个账号 → 点 **打开浏览器检查登录**。窗口里如果要求登录，扫码登录一次（这个窗口会长期保留登录态）；
3. 回到「今天要发的」，点 **仅演练（不发布）** 跑一遍。演练只走到"填好标题"就停，不会真的发布。

> 演练通过后就可以正常用了。第一次真实发布建议你在旁边看一眼。

## 五、每天怎么用

1. 把当天视频放进各账号的素材文件夹（顺序＝文件名排序，视频1 → 视频2 → 视频10）；
2. 在账号行点 **粘贴广告语**：先在表格里选中广告语那一列按 Ctrl+C，再在弹窗里点「从剪贴板粘贴」；
3. 弹窗底部会实时显示"视频 12 个 / 广告语 12 条"，数量对上后点「保存并关闭」（广告语会自动存下来，关掉工具再打开还在）；
4. 点 **▶ 开始上传发布**。每个账号开始前会弹出对照表，核对「文件名 和 广告语」是否一条条对上，确认后开始跑；
5. 跑完在 **报表** 目录看《运行结果_日期.xlsx》；中途看进度点右上角「今日进度」。

进度条下面会显示「已完成 7 / 24 条 · 已用 25 分钟 · 预计还需 1 小时 10 分」。

### 多个账号同时跑

主界面有 **并行执行已勾选账号** 按钮，旁边可以设置 **同时最多 N 个账号**（默认 2，范围 1-5）。

- 并行只发生在账号之间；每个账号内部仍然逐条上传、逐条发布、逐条等待，顺序不会乱。
- 某个账号发布结束后，会立即开始自己的金牛改名，不必等其他账号发布完。
- 某个账号失败或点「停止该账号」，只停该账号；顶部「停止」按钮会停全部。
- 并行前会检查账号是否共用浏览器目录、调试端口、登录配置或金牛账户ID；冲突时会禁止并行并提示。
- 并行会共用同一条网络和同一个 IP，可能让上传变慢或增加平台风控压力；如果实际不稳定，把并发数降到 1，或改用普通串行按钮。

### 作者声明和定时发布

账号卡片里的 **查看对照表** 现在升级成“左边看顺序、右边改设置”：

- **作者声明**：逐条选择，默认「不设置」。页面上的选项包括内容为AI生成、演绎情节仅供娱乐、个人观点仅供参考、素材来源于网络。选不上会重试 2 次，仍失败就跳过这一条并记录，不会带着错误声明发布。
- **发布时间**：逐条选择“立即发布”或“定时发布”。平台规则是只支持未来 1 小时到 14 天内；工具默认设置为当前时间 61 分钟后，避开边界。
- 只要账号里有定时发布，本次运行就不会自动执行金牛改名；工具会把待改素材写进台账，下次打开时提醒你手动点「只改金牛素材名」。
- 作者声明只在本次打开工具期间有效；如果中途重开，未发布视频会按空声明继续。定时时间会保存在当天进度里。

### 设置页和主界面的分工

- **设置页**：维护账号名、浏览器、登录方式、金牛账户ID、删除账号。
- **今天要发的**：每天勾选「今天要发这个账号」、选择素材文件夹、粘贴广告语。
- 设置页不再重复显示「启用」和「素材文件夹」；账号名在主界面为只读显示，统一到设置页修改。

## 六、顺序和安全机制

- **顺序即对应关系**：发布顺序＝文件名自然排序，广告语按你粘贴的行顺序一一对应。
- **一条一条来**：上一条确认发布成功后，固定等 15 秒再做下一条，保证发布顺序不错乱。
- **不跳步**：某条结果不确定（超时、页面变了、网络断了）会立刻停下等你处理，绝不跳过——跳过一条会让后面全部错位。
- **断点续跑**：已发布成功的条目会记进 `runs/`，重开工具从断点继续，不会重复发布。
- **发布前确认**：每个账号开跑前都有对照表让你核对。
- **异常即停**：登录失效、验证码、页面改版都会停下并截图；提示框里可以选择"我已手动完成，继续"。
- **防休眠**：运行期间自动阻止电脑休眠（屏幕可以关），但请不要关机。

## 七、金牛改名是怎么做的

设置页可以选三种方式：

| 方式 | 逻辑 |
| --- | --- |
| **先按广告语搜索素材再改名（推荐）** | 用每条广告语在素材库搜索框里查一次，搜到的那条素材改名为对应的视频文件名，改完再搜一次确认旧名字已经搜不到 |
| 按上传时间倒序批量改名 | 读取当日新增素材（金牛最新在最上面），**倒序**与文件夹里的视频一一对应后批量改名 |
| 自动：先试搜索，失败再按时间 | 默认方式，先用搜索方式，若匹配不上自动改用按时间倒序 |

不论哪种方式，改名之前都会弹出「素材当前名 → 要改成的新素材名」对照表让你确认；改完会截图留证，个别没改成功的会标成"待核对"写进报表。

## 八、常见问题

**1. 同事的浏览器不是 Google Chrome，也没有多个用户配置？**
点「＋ 添加账号」加一行，浏览器下拉里选他实际用的那个（Edge、360 极速、QQ 浏览器等都支持）；登录方式选「新建：首次扫码登录」，让他第一次扫码登录一次就行。

**2. 弹出「需要你手动…」的提示框？**
说明脚本没认出页面上某个元素。照着提示在浏览器窗口里手动做一步，再选对应选项继续；同时把 `logs/shots/` 里最新的截图发我。

**3. 提示登录失效？**
在那个自动化浏览器窗口里扫码登录，然后重新启动该账号，脚本会从断点继续。

**4. 为什么这么慢？**
单条视频 300MB 以上，又要串行 + 每条间隔 10 秒，主要受上传带宽限制。建议晚上开跑、早上看报表；也可以分批，比如上午 3 个账号、下午 2 个账号。

**5. 只想改金牛素材名 / 这次不想改名？**
点「只改金牛素材名」；或取消勾选「上传发布完成后自动改名」。

**6. 要设置封面/话题/合集/地点？**
这些属于"每账号固定值"，配置在 `config/config.json` 的 `accounts[].extra_actions`，例如：

```json
"extra_actions": [
  { "do": "click", "label": "勾选合集", "target": [{ "text": "选择合集" }] },
  { "do": "fill",  "label": "填话题",   "target": [{ "placeholder": "添加话题" }], "value": "#好物推荐" }
]
```

支持 `click`、`fill`、`check`、`set_files`、`wait` 五种动作，勘查之后我可以帮你填好。

**7. 换电脑或换人用？**
把整个「快手自动发布助手」文件夹拷过去，新电脑上重做一次"引导设置 + 打开浏览器检查登录（扫码）"即可。

## 九、目录结构

```
快手自动发布助手/
├─ 启动工具.bat          ← 每天用这个
├─ 准备浏览器配置.bat     ← 命令行版（界面里也能做，可不用）
├─ 运行勘查.bat           ← 页面改版时抓页面结构
├─ 自检.bat               ← 环境自检，不碰账号
├─ app/                   ← 程序代码
├─ config/
│   ├─ config.json        ← 账号、网址、节奏（界面里改更方便）
│   └─ selectors.json     ← 后台页面元素规则（由助手维护）
├─ logs/                  ← 运行日志、异常截图、页面勘查快照
├─ runs/                  ← 当天进度 + 当天广告语（断点续跑用）
├─ 界面预览/              ← 界面截图
└─ 报表/                  ← 每天跑完生成的《运行结果_日期.xlsx》
```

## 十、已知限制与风险

- 平台页面改版后可能找不到元素，脚本会停下并截图，改 `selectors.json` 即可恢复。
- 平台风控、验证码、二次校验不在自动化范围内，遇到会交回给你人工处理。
- 作品是**公开发布**的，所以工具用"演练 + 逐账号确认 + 异常即停"来兜底。
- 非 Chromium 内核的浏览器（如 Firefox）无法被接管；这种情况请在浏览器下拉里选一个本机已装的 Chromium 浏览器，用「新建：首次扫码登录」方式跑。
- 不建议使用市面第三方"批量上传工具"：它们通常要你交出账号密码或登录凭证，存在盗号与封号风险。

## 十一、退路方案

如果某天平台风控导致自动化不稳定，最低成本的替代做法是：把素材目录里的视频**提前批量重命名成广告语**，再手动上传，这样平台默认标题就是对的，也能省掉大部分重复输入。
